# 📝 Notes App — React приложение для заметок

Простое и элегантное приложение для создания и управления заметками с автоматическим сохранением и поиском.

## ✨ Возможности

| Функция | Описание |
|---------|----------|
| **📌 Создание заметок** | Добавляйте заметки с автоматической временной меткой |
| **✏️ Редактирование** | Кликните по заметке для редактирования |
| **🗑️ Удаление** | Легко удаляйте ненужные заметки |
| **🔍 Поиск** | Быстрый поиск по тексту заметок |
| **💾 Автосохранение** | Все заметки сохраняются в localStorage |
| **🎨 Стильный интерфейс** | Красивое оформление с тетрадной разлиновкой |

**Демо:** 🔗 [https://ilyarusin.github.io/notepad-app/](https://ilyarusin.github.io/notepad-app/)

## 🚀 Установка и запуск

```bash

git clone https://github.com/ilyarusin/notes-app.git

# Перейти в папку проекта
cd notes-app

# Установить зависимости
npm install

# Запустить в режиме разработки
